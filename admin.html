Nhập dữ liệu từ file Thông báo (Word/PDF)

Chọn file Thông báo Lịch phân xe (.docx hoặc .pdf) để tự động đọc và điền vào lịch của tuần đang chọn ở bên dưới. Hệ thống sẽ tự tách nội dung từng ô thành buổi Sáng/Chiều theo giờ ghi trong văn bản. Khuyến nghị dùng file Word (.docx) để có kết quả chính xác nhất; file PDF là tính năng thử nghiệm. Sau khi nhập, vui lòng kiểm tra lại từng ô trước khi bấm "Lưu lịch phân xe tuần này".
